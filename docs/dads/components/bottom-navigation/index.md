# ボトムナビゲーション

[2026年9月9日更新](changelog.md)

## \[エラー]このコンポーネントの使用は非推奨です（deprecated）

このコンポーネントはアクセシビリティまたはユーザビリティの観点等から、現在は使用が推奨されません。

やむを得ず使用する場合は、不利益があるユーザーの存在を踏まえたうえで注意深く使用してください。

## 本コンポーネントの非推奨理由

ボトムナビゲーションは、現在は使用が推奨されていません。

画面下部にナビゲーションを固定すると、操作しようとした際にモバイルブラウザのUIやジェスチャー領域と競合するおそれがあります。

また、ナビゲーションをDOMの最下部に固定配置した場合、視覚的に見えているにも関わらず、キーボード操作では最下部までフォーカスを移動しなければならず、アクセスしにくくなります。ナビゲーションをDOMの最下部に配置すると、スクリーンリーダーでもナビゲーションを見つけることが難しくなります。

代わりに、水平メニューをページ上部に配置してください。モバイルでは、ハンバーガーメニューボタンとモバイルメニューを組み合わせて使用してください。
